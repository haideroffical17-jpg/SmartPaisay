Firebase Connection Setup Guide

Aapka Firestore timeout error is wajah se aa raha hai kyunki aapke Firebase Console mein Anonymous Auth ya Firestore Settings enable nahi hain. Isay 2 minute mein theek karne ka aasan tareeqa:

1

Anonymous Sign-In Enable Karein

Apne Firebase Console me left menu se Authentication pe click karein. Phir Sign-in method tab me ja kar Anonymous provider ko select karke Enable karein aur save kar dein.

2

Database Rules Public Karein

Left menu se Firestore Database pe jayein aur Rules tab par click karein. Wahan maujood code ko is code se badal kar Publish kar dein: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
3

Offline Failsafe Active Rahega!

Aapki is app me humne Local Storage auto-save add kar diya hai. Ab agar Firebase connect na bhi ho sake, tab bhi aapka data aapke local web browser me 100% save rahega bina kisi fikar ke!
